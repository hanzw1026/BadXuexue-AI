========================================
        SnowAI 一键安装说明
========================================

【系统要求】
- Windows 10/11 (64位)
- 4GB 以上内存
- 2GB 以上磁盘空间

【安装步骤】

1. 右键管理员方式运行 Windows安装_管理员运行这个.bat
   （如果提示管理员权限，请允许）

2. 等待自动安装完成（约5-10分钟）
   - 自动安装 VC++ 运行库
   - 自动安装 Poppler（PDF工具）
   - 自动安装 Tesseract（OCR工具）
   - 自动安装 Python 环境
   - 自动安装 Python 依赖包
   - 自动下载 AI 模型

3. 安装完成后，提示重启电脑
   【重要】必须重启！

4. 重启后，双击桌面 SnowAI 图标启动

【使用说明】

1. 首次启动可能需要30秒加载模型
2. 点击"本地知识库"上传文档
3. 支持格式：PDF、Word、TXT、Markdown
4. 扫描版PDF会自动OCR识别

【常见问题】

Q: 安装过程中断怎么办？
A: 重新运行安装脚本即可

Q: 桌面没有快捷方式？
A: 手动进入文件夹双击 start.bat 启动

Q: OCR不工作？
A: 请确认已重启电脑

【注意事项】

- 安装过程中请勿关闭窗口
- 需要联网下载Python和依赖包
- 杀毒软件可能误报，请允许运行
