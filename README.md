🐾 项目起源
一位硬件工程师在重复计算EMI电路参数时想：“为什么我不能像问朋友一样，直接告诉电脑‘我要一个在1MHz衰减40dB的滤波器’？” 
于是，这个工具诞生了——它始于一个午后的烦躁，成长于无数个深夜的调试，最终开源给所有曾为重复计算皱眉的同行。


🔧 它能做什么（以下为雪雪自己的日常用法）
对话式电路设计：用自然语言描述需求，获取电路拓扑与参数建议
智能计算伙伴：处理信号链设计、EMI优化、热仿真预处理等重复性计算
知识沉淀工具：将你的设计习惯逐步转化为可复用的规则库

你的用法：你自己摸索哦～


**🎯 设计哲学**
> 雪雪相信，硬件工程师的时间应该花在**创造**而非**计算**上。
> 就像程序员不再需要记忆机器码，硬件工程师也不该被困在公式手册里。
> 推而广之，所有的岗位，每个人都时间都要尽量避免花在简单重复性工作上。

📦 一键安装
下载 zip 解压
Windows用户：
	1.管理员模式运行——Windows安装_管理员运行这个.bat；
	2.等待自动安装 Python 和依赖；
	3.双击桌面快捷方式启动；

MacOS用户：
	1.雪雪写了个脚本，但是没自己亲自试过，你们可以帮雪雪试试；
	2.因为雪雪是用MacOS开发的这个工具，因此估计问题不大，如果需要，雪雪可以出个txt文档，你打开终端复制粘贴进去等着他执行完就可以了；

Linux用户：
	1.大佬，雪雪都给你源代码了哦，大神你就sudo apt-get就好啦～
